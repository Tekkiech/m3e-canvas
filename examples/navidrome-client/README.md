# Navitune: a Navidrome client that looks like ArchiveTune

A ready-to-paste prompt for an AI coding tool (Claude Code, Codex, Gemini CLI, Cursor) that builds a native Android music player for a self-hosted [Navidrome](https://www.navidrome.org/) server, styled after [ArchiveTune](https://github.com/Tekkiech/archivetuneapp).

## How the prompt was made

1. ArchiveTune's Compose source was read for its visual system: the coral seed `#ED5564` with colors re-seeded from the playing song's artwork, Poppins, 8/12/16/24/32dp shapes, the expressive motion scheme, the floating pill navigation bar with the mini player docked on it, and the "Cinematic" player (`PlayerDesignStyle.V4`).
2. Those screens were redrawn as an M3E Canvas document for a Navidrome client: Connect, Home, Search, Library, Album, Artist, Now playing, Queue, Lyrics and Settings. The part notes carry ArchiveTune's exact sizes and the Subsonic endpoint behind each part.
3. The canvas's own `buildPrompt` (English, Android, light and dark, dynamic color) wrote everything in `PROMPT.md` above the `---` line.
4. The part below the line was written by hand. It covers what a sketch cannot: the artwork-driven theme and player backgrounds, the Subsonic / OpenSubsonic data layer (token auth, Cloudflare Access headers, stable cache keys for salted URLs), Media3 playback, settings, the stack (matching ArchiveTune's), tests, scope and acceptance criteria.

If you change the sketch in the canvas, copy the new prompt from its Prompt panel and replace everything above the `---` line in `PROMPT.md`.
